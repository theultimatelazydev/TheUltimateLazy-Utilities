# Changelog

All notable changes to this package are documented in this file. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the package uses [Semantic Versioning](https://semver.org/).

## [0.2.0]

### Added
- `UltimateLazyDev/UI/Grayscale` shader and `GrayscaleUI` material: grayscale for uGUI graphics, with stencil masking,
  `RectMask2D` clipping and alpha clip, in Built-in and URP.

## [0.1.1]

### Added
- Grayscale 2D shaders and materials for Built-in and URP.
